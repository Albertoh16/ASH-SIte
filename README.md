# ASH Site - Personal Portfolio Website

A modern, interactive personal portfolio website showcasing professional experience, programming projects, and contact information. Built with React and Tailwind CSS, featuring smooth animations and a fully responsive design.

**Live Site:** [https://albertoh16.github.io/ASH-SIte/](https://albertoh16.github.io/ASH-SIte/)

## Overview

ASH Site (Alberto Sebastian Hernandez) is a personal portfolio designed to create a unique digital presence on the web. The site features an eye-catching dark theme with custom animations, interactive expandable sections, and dynamic project integration with GitHub.

## Features

- **Home Page**
- **Experience Page**
- **Projects Page**
- **Contacts Page**

### Design Features

- **Fully Responsive**: Optimized for all screen sizes from mobile (320px) to 4K displays
- **Custom Color Scheme**: Dark theme with crimson accents
- **Smooth Animations**: Framer Motion library for fluid transitions and interactions
- **Custom Tailwind Configuration**: Extended breakpoints and animations
- **Professional Typography**: Clean, readable fonts with proper hierarchy
- **Interactive Elements**: Hover effects, click animations, and smooth scrolling

## Tech Stack

### Frontend Framework
- **React 19.1.0**: Component-based UI architecture
- **React Router DOM 7.5.0**: Client-side routing for SPA navigation

### Styling
- **Tailwind CSS 3.4.17**: Utility-first CSS framework
- **@tailwindcss/typography 0.5.19**: Beautiful typographic defaults
- **PostCSS 8.5.3**: CSS transformations and autoprefixing

### Animations
- **Framer Motion 12.7.2**: Production-ready motion library for React

### Content Rendering
- **React Markdown 10.1.0**: Markdown to React component rendering
- **remark-gfm 4.0.1**: GitHub Flavored Markdown support

### API Integration
- **Axios 1.9.0**: HTTP client for GitHub API requests
- **GitHub REST API**: Fetches repository data and README files

### Testing
- **@testing-library/react 16.3.0**: React component testing
- **@testing-library/jest-dom 6.6.3**: Custom Jest matchers
- **@testing-library/user-event 13.5.0**: User interaction simulation

### Deployment
- **gh-pages 6.3.0**: GitHub Pages deployment automation
